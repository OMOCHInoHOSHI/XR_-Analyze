# ADR-0021: 円盤は鑑定法ではなくモードを選び、調整も同じ輪に並べる

- ステータス: 承認済み
- 記録日: 2026-08-30
- 関連: [ADR-0007](0007-viewport-crop-calibration.md), [ADR-0010](0010-client-side-display-policy.md), [ADR-0014](0014-box-theme-and-dom-reuse.md), [ADR-0019](0019-key-binding-policy-v2.md), [ADR-0020](0020-arrow-target-navigation.md)

## 文脈

[ADR-0019](0019-key-binding-policy-v2.md) で、鑑定法の選択は `m` で開く円盤に、
映像の調整は `c` で出入りする調整モードに、それぞれ分けて置いた。

結果として「今どのモードにいるか」を変える入口が2つに割れた。利用者から見れば、
単体鑑定にするのも調整に入るのも同じ「モードを変える」操作である。

円盤には鑑定法しか並んでおらず、調整に入る手段は `c` のキーを覚えているかどうかに
依存していた。画面のどこにも出ていない。

## 決定

- 円盤の項目を**モード**とし、鑑定法(単体鑑定 / 広域鑑定)に加えて**調整**を並べる。
  円盤の見出しも `モ ー ド` に変える。
- 鑑定法と調整は**排他**に扱う。「現在」の印は常に1つだけ付く。調整を選べば
  鑑定法は覚えたまま調整へ入り、鑑定法を選べば調整から抜ける。
- **選び直しただけなら解除しない**。調整中に今と同じ鑑定法を選んだ場合は、調整から
  抜けるだけで選択・固定は残す。
- **調整モード中も `m` だけは効かせる**。`Enter` と矢印による対象選択は、
  ADR-0019 のとおり動かさないままにする。
- `c` のトグルは残す。
- ADR-0019 の他の決定(矢印は鑑定の操作に充てる、調整は `c` の中へ隔離する、
  数字は即確定・矢印は Enter 確定、無操作3秒で自動キャンセル、Ctrl/Cmd/Alt には
  反応せず Shift は除外しない)はそのまま引き継ぐ。

## 理由

- **入口を1つにまとめる**: 「今どのモードにいるか」という問いに対して、鑑定法と
  調整で別々の入口を用意する理由がない。円盤に並べれば、調整という機能があること
  自体が画面から分かる。`c` を覚えていなくてもたどり着ける。
- **排他にする**: 実態としては直交している(調整中も鑑定法は生きている)。しかし
  「現在」の印が2つ付くと、盤を見ても今どういう状態なのかが一目で読めない。
  調整中は枠を操作しないので、表示上1つに畳んでも失うものがない。
- **選び直しで解除しない**: ADR-0020 で「同じ鑑定法の選び直しでは解除しない」と
  決めた理由と同じ。調整から抜けるために元の鑑定法を選ぶのは自然な導線であり、
  そこで固定が外れると「固定は明示的な解除でだけ外れる」前提が壊れる。
- **調整中に `m` を効かせる**: 円盤に調整を載せた以上、そこから戻れないと入口だけ
  片道になる。円盤が開いている間はすべてのキーを盤が吸収するため、矢印が位置調整に
  漏れることはない。ADR-0019 の「調整中は鑑定の操作を動かさない」は、モードを移る
  操作までは想定していなかった。
- **`c` を残す**: 据え付け時は調整に何度も出入りする。円盤経由は `m` → `3` の
  2ストロークで、単独キーより手数が多い。使用頻度の高い場面のための近道として残す。
- **環のあしらいを左右へ移す**: 項目は12時から等間隔に並ぶため、上下に置くと
  2件のときは12時と6時、3件のときは12時が項目の下に隠れる。左右ならどちらでも
  重ならない。

## 結果

- モードを増やすときは `MODES` に1行足すだけでよい、という ADR-0019 の性質は
  そのまま残る。調整もその1行として並んでいる。
- **引き受けた制約**: 「現在」の印が1つに畳まれるため、調整中は円盤を見ても
  元の鑑定法が分からない。鑑定盤の「鑑定法」の行には出ているので、そちらで補う。
- **引き受けた制約**: 意匠の切替(暫定のデバッグ機能)が数字 `1`〜`6` を使っている
  ため、モードが7件以上に増えると数字キーが衝突する。円盤が開いている間は盤が
  すべてのキーを吸収するので現状は問題ない。ADR-0019 から引き継ぐ既知の制約である。
- ADR-0019 はこの ADR で置換する。

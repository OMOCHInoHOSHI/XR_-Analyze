# ADR-0014: 意匠は CSS で切り替え、枠の DOM は毎フレーム使い回す

- ステータス: 承認済み (意匠の切替キーは暫定・削除予定)
- 記録日: 2026-08-18
- 関連: [ADR-0010](0010-client-side-display-policy.md), [ADR-0015](0015-key-binding-policy.md)

## 文脈

「鑑定」というテーマに合う枠のデザイン (意匠) を、実機のグラス越しで見比べて決めたい。
候補は走査線・円陣・波紋のようにアニメーションを伴う。

一方、枠は毎フレーム位置とサイズが変わるため、素朴に実装すると毎フレーム DOM を
作り直すことになる。

## 決定

- 意匠は `#stage` の `data-theme` と色トークン (`--c` 系) で、**CSS のみで切り替える**。
- 数字キー 1〜6 での切り替えは**暫定のデバッグ機能**とし、意匠が確定したら機能ごと削除する。
- 既定の意匠は**配列の添字ではなく id で指定**する (現在は `"azure"` = 六: 蒼環の菱標)。
- 枠の要素は毎フレーム作り直さず、**プールから使い回す**。

## 理由

- **CSS だけで切り替える**: 描画ロジックを意匠ごとに分岐させずに済む。JS 側は位置と
  テキストの更新だけを担い、見た目は完全に CSS へ寄せられる。
- **既定を id で指す**: キー割り当てや配列の並びを変えても既定がずれない。
- **DOM を使い回す**: 毎フレーム DOM を捨てて作ると、走査線や円陣の CSS アニメーションが
  常に先頭へ巻き戻り、**まったく進まない**。子要素は `[label, d1, d2]` の順で固定し、
  余った枠は `display: none` で隠す。
- **色は `--c` を使う側の要素で直接参照する**: CSS カスタムプロパティは `var()` を
  解決した時点で値が確定し、その確定値が継承される。中間変数 (`--label-bg` など) に
  `var(--c)` を入れて `#stage` で定義すると、そこで値が固まってしまい、子孫の
  `.box.locked` が `--c` を上書きしてもラベルだけ色が変わらなくなる。
- **鑑定盤は DOM を固定してテキストだけ差し替える**: 検出名を扱うため `innerHTML` は使わない。

## 結果

- 使い回すのは「n 番目の枠」であって物体ではない。広域鑑定では毎フレーム信頼度順に
  並べ替えるため、同じスロットが別の物体を指すことがある (アニメーションの位相が物体に
  紐づくのは単体鑑定 / 固定中だけ)。表示そのものはどちらでも壊れない。
- 採用した `六` と `伍` は**引き出し線の向きを右上に固定**しているため、画面の右上端に
  ある対象では銘板が画面外へはみ出す。向きの自動反転は未実装で、意匠を確定するなら
  反転処理の追加が必要。
- 鑑定盤は選択肢の開閉で高さが変わるため、デバッグ行は絶対配置にせず盤の下に流している。

## 暫定機能の削除手順

意匠が確定したら、`frontend/index.html` の以下を削除する。

- `<script>` 内の `// --- [DEBUG] 意匠(デザイン)の切り替え ---` から
  `// --- [DEBUG] ここまで ---` までのブロック
- `keydown` の `default:` 節
- `render()` 内の `themePart` (宣言と `hud.textContent` への連結の両方)
- `<style>` 内の `意匠 壱: 蒼の走査` の見出しコメント以降すべて (意匠ごとの
  `#stage[data-theme=...]` ブロックに加え、`@keyframes scan / breathe / spin /
  spin-rev / ping / glim` と `@supports` も含む)

**注意**: `DEBUG_THEME_KEYS` を `false` にするだけだと `data-theme` が付かず、
ベース CSS の「肆: 素の緑」に戻ってしまう。採用する意匠
(`#stage[data-theme="azure"]`) の各宣言を、先にベース側
(`#stage` / `.box` / `.label` / `.d1` / `.d2`) へ畳み込んでから削除すること。

### 意匠の候補 (比較用)

| キー | 意匠 | 内容 |
|---|---|---|
| `1` | 壱: 蒼の走査 | 四隅の鉤括弧だけを光らせ、枠内を走査線が上下する。固定で走査が止まり内側に確定枠 |
| `2` | 弐: 金の魔導書 | 二重枠と四隅の菱形。菱形が明滅し、固定すると止まって開く。ラベルは枠の下 |
| `3` | 参: 紫の秘術陣 | 対象の中心に二重の円陣を重ね、外周と内周を逆回転。固定で金色になり加速 |
| `4` | 肆: 素の緑 | 従来の見た目 (比較用のベース CSS) |
| `5` | 伍: 白環の銘板 | 四角い枠を出さず環 (楕円) で対象を囲み、環の右上から引き出し線を伸ばして先端の銘板に名前を出す。捕捉中は環から波紋、固定で波紋が止まり環が二重に |
| `6` | 六: 蒼環の菱標 | **採用**。`伍` の構図に `壱` の配色と菱形のあしらいを載せた組み合わせ。環の上・左・下と引き出し線の起点に菱形を置き、明滅させる。固定で明滅が止まり菱形が開く |

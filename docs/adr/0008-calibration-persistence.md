# ADR-0008: 合わせ込み値を calib.json にアトミックに永続化する

- ステータス: 承認済み
- 記録日: 2026-08-18
- 関連: [ADR-0004](0004-config-resolution-order.md), [ADR-0007](0007-viewport-crop-calibration.md)

## 文脈

グラスに合わせ込んだズーム / 切り抜き位置 ([ADR-0007](0007-viewport-crop-calibration.md)) を
毎回やり直すのは現実的でない。一方でこの値は機材・装着位置ごとに変わるため、
コードや共有設定に埋め込むものでもない。

## 決定

- 確定値をプロジェクトルートの `calib.json` (環境変数 `CALIB_FILE` で変更可) に保存し、
  次回起動時の初期値として読む。
- 保存は**一時ファイルへ書いてから `os.replace` で差し替える**。
- 読み込みに失敗しても**起動は止めず**、警告を出して既定値で立ち上げる。
- 保存先パスは `__file__` 基準で決める。

## 理由

- **アトミックに差し替える**: 保存の途中で落ちると壊れた JSON が残り、次回起動が
  「読めないファイル」で既定値に戻る。`os.replace` は同一ディレクトリ内ならアトミックなので、
  中断しても直前の内容が残る。
- **読み込み失敗で落とさない**: 合わせ込みはやり直せるが、起動不能は復旧が重い。
  ファイルが無い / 壊れている / 形式が違う、のいずれでも空として扱って起動を通す。
- **`__file__` 基準**: どのカレントディレクトリから起動しても同じファイルを読み書きするため。
  相対パスだと起動場所によって別のファイルを見てしまう。
- **保存値は「明示指定が無いときの既定値」**: 環境変数が常に勝つ
  ([ADR-0004](0004-config-resolution-order.md))。保存値を使わず一時的に別の値で試せる。

## 結果

- `calib.json` は機材ごとに変わる値なので `.gitignore` に入れてある。
- `check_camera` も同じ `calib.json` を初期値として読む。ただし `check_camera` では
  `s` キーが「下方向へ移動」に割り当て済みのため、保存はブラウザ画面から行う。
- 値の検証で `bool` は明示的に除いている (`bool` は `int` のサブクラスなので、
  `true` が `1.0` として通ってしまう)。
- 保存する JSON には `saved_at` も含めるが、読み込み側は `zoom` / `offset_x` / `offset_y` の
  3 キーしか見ない。将来キーを増やしても古いファイルを読めるようにするため。

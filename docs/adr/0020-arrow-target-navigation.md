# ADR-0020: 単体鑑定の対象は矢印の空間方向で選び替え、選択と固定を分ける

- ステータス: 置換 (ADR-0022 による)
- 記録日: 2026-08-29
- 関連: [ADR-0010](0010-client-side-display-policy.md), [ADR-0011](0011-gaze-target-selection.md), [ADR-0012](0012-lock-tracking-by-iou.md), [ADR-0013](0013-overlay-coordinate-basis.md), [ADR-0014](0014-box-theme-and-dom-reuse.md), [ADR-0019](0019-key-binding-policy-v2.md), [ADR-0022](0022-arrow-navigation-wraps.md)

## 文脈

[ADR-0011](0011-gaze-target-selection.md) により、単体鑑定の対象は毎フレーム
照準 (画面中心) から決まる。狙いたい物体の手前に別の物体があるときや、対象が
密集しているときに、頭の向きだけでは狙い分けられない。

対象を保持する手段は `Enter` の固定しかなく
([ADR-0012](0012-lock-tracking-by-iou.md))、「固定はせずに対象だけ隣へ動かして
見比べる」ことができなかった。

## 決定

- 単体鑑定で矢印キーを押すと、**今の対象 (無ければ照準) から見てその向きにある
  最も近い検出**へ対象を移す。距離は表示ピクセルで測る (ADR-0013 の実表示矩形が
  基準)。
- 候補は「進む向きの成分が 2px を超え、かつ横にずれた分がその 2 倍以内 (約 63°の
  円錐)」のものに限る。その中で「進む向きの成分 + 横にずれた分 × 2」が最小のものを
  選ぶ。同点なら信頼度の高い方。
- 照準ベースの選択にある**半径の足切り (`GAZE_RADIUS`) は矢印には適用しない**。
- 対象の状態を **照準ベース → 選択中 → 固定** の 3 段にする。矢印で選ぶと
  「選択中」、`Enter` で「固定」、`Esc` で照準ベースへ戻る。固定中に矢印を押すと
  選択中へ降格したうえで隣へ移る。ただし**降格するのは移動が成立したときだけ**で、
  その向きに候補が無ければ固定はそのまま残す。
- 鑑定法を選び直しても、それが**今と同じ鑑定法なら選択も固定も解除しない**。
  解除するのは実際に鑑定法が変わったときだけである。
- 「選択中」も「固定」と同じ IoU 追従 (ADR-0012) で対象を引き継ぎ、見失ったら
  2 秒で解除する。
- 選択中は枠の外側に破線 (`.box.picked` の `outline`) を出し、ラベルに `[選択]`
  を付ける。照準は薄くする。

## 理由

- **空間方向で選ぶ**: 候補リストの順送りだと「次にどれが選ばれるか」が画面から
  予測できない。XR では頭を向けて対象を狙うため、「右にあるものへ」という指示が
  空間の理解とそのまま対応する方向ナビのほうが直感に合う。
- **横ずれに重みを付ける**: 向きの成分だけで選ぶと、真横に遠く離れたものより
  斜め手前のものが勝ち、`→` を押したのに斜め上へ跳ぶ。重み付きの減点なら、
  まっすぐ隣を優先しつつ斜めの候補も拾える。
- **減点に加えて円錐でも足切りする**: 減点だけでは足りない。この式は前進量が
  小さいほど有利になるため、**わずかに前・大きく横**の検出が、正しくその向きにある
  遠い検出に勝つ。実測で、前進 5px・横 278px の検出 (スコア 562) が、前進 400px・
  横 538px の真上の検出 (スコア 1475) に勝ち、`↑` を押して横へ跳ぶ事象を確認した。
  円錐を 45°まで絞ると「押しても動かない」場面が増えるため、**約 63° (横ずれは
  前進量の 2 倍まで)** という緩い円錐にして、順位付けは従来どおり減点で行う。
- **半径で足切りしない**: `GAZE_RADIUS` は「見ていないものに勝手にフォーカスしない」
  ための制限 (ADR-0011)。矢印は利用者が意図して選びに行く操作なので、勝手に
  選ばれる心配がなく、遠くの対象へ届かないほうが困る。
- **選択と固定を分ける**: 矢印で選んだ時点で固定にすると、対象を隣へ動かして
  見比べるたびに固定を解除する操作が要る。一方で選択を毎フレーム捨てると、次の
  フレームで照準ベースに戻ってしまい選び替えが成立しない。追従はするが固定ではない
  中間の段を置いた。
- **固定中の矢印は選択中へ降格する**: 固定したまま隣へ移せると、「固定している」
  という状態の意味が薄れる。固定は `Enter` で明示的にやり直させる。移動が成立
  しなかったときまで降格すると、「押しても動かなかった」だけで固定が外れる。
- **同じ鑑定法の選び直しでは解除しない**: 円盤のカーソルは今の鑑定法から始まるため、
  盤を開いて確認しそのまま確定して閉じる操作は `Enter` の空打ちになる。ここで
  解除すると、「固定は明示的な解除操作でだけ外れる」という前提が壊れる。
- **見た目を分ける**: 照準が決めた対象と、利用者が選んだ対象は意味が違う。
  `outline` を使うのは、どの意匠も `border` と装飾レイヤ (`.d1`/`.d2`) を使っている
  ためで、意匠を足すときの負担にならない (ADR-0014)。

## 結果

- 密集した物体でも狙い分けられるようになった。頭を動かさずに視界内の対象を渡り
  歩ける。
- **制約**: 候補はサーバが配信する検出だけである。`MAX_DET` (既定15) を超える場面では、
  矢印でも届かない物体が残る (ADR-0010)。
- **制約**: 追従は IoU による簡易的なもので、同種の物体が重なる場面では乗り移り
  うる (ADR-0012)。選択中も固定と同じ仕組みなので同じ弱点を持つ。
- 横ずれの重み (`NAV_CROSS_WEIGHT`, 既定 2)、円錐の広さ (`NAV_CONE`, 既定 2)、
  最小の前進量 (`NAV_MIN_PX`, 既定 2) は調整点として残す。
- **制約**: 自分自身の除外は位置の近さ (`NAV_MIN_PX`) だけに頼っている。検出枠は
  同じ物体でもフレーム間で数 px 動くため、押した向きへのぶれがこの値を超えると、
  隣の物体ではなく「少し動いた自分自身」が選び直されうる。表示上は同じラベルが
  ほぼ同じ位置に出るだけなので実害は小さいが、値の妥当性は実機で確かめたい。

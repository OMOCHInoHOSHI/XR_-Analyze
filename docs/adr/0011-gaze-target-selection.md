# ADR-0011: 単体鑑定の対象は照準の包含 → 半径内の最近傍で決める

- ステータス: 承認済み
- 記録日: 2026-08-18
- 関連: [ADR-0010](0010-client-side-display-policy.md), [ADR-0012](0012-lock-tracking-by-iou.md), [ADR-0013](0013-overlay-coordinate-basis.md)

## 文脈

単体鑑定では常に 1 件だけ枠を出す。XR グラスでは頭を向けて対象を狙うため、
**画面中央 = 見ているもの**として扱える。

ただし「画面中央に何も無いとき」に何を選ぶかを決めないと、視界の隅の物体が
勝手にフォーカスされる。

## 決定

表示する 1 件を次の順で決める。

1. **画面中心 (照準) を含む検出**。複数あれば**面積の小さい方**
2. 無ければ、照準から**表示領域の短辺の `GAZE_RADIUS` (既定 0.25) 以内**で最も近い検出。
   同距離なら信頼度の高い方
3. どちらも無ければ**枠を出さない**

距離は正規化座標ではなく**表示ピクセル**で測る。

## 理由

- **包含を最優先し、小さい方を採る**: 机や壁のような大きな物体より、具体的な対象を
  指したい。中心を含む検出が複数あるとき、面積が小さいほうがより具体的である。
- **半径で足切りする**: これが無いと、中央に何も無いときに視界の隅の物体が必ず選ばれる。
  「見ていないものに勝手にフォーカスしない」ほうが、誤った対象を掴むより扱いやすい。
- **表示ピクセルで測る**: 正規化座標 (0-1) のまま `dx*dx + dy*dy` で測ると、16:9 では
  x の 1 単位 = 幅・y の 1 単位 = 高さのため**横方向のズレが 1.78 倍過小評価**され、
  画面端の物体が中央脇の物体に勝つ。実測で、端 560px の物体が中央脇 320px の物体に
  勝つ事象を確認した。基準となる矩形は
  [ADR-0013](0013-overlay-coordinate-basis.md) の実表示矩形を使う。
- **同距離では信頼度の高い方**: ちらつきの原因になる同点を残さない。

## 結果

- 照準は画面中央に小さな菱形で表示し、単体鑑定のときだけ出す。広域鑑定は中心で
  絞り込まないため、照準を出しても意味を持たない。
- `GAZE_RADIUS` は調整点として残す。狙いを合わせにくいときは大きく、余計なものを
  拾うときは小さくする。
- この選択は毎フレーム独立に行うため、対象を保持したい場合は固定 (Enter) を使う
  ([ADR-0012](0012-lock-tracking-by-iou.md))。

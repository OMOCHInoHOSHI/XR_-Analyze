# ADR-0019: 矢印キーは鑑定の操作に充て、映像の調整は 'c' の中へ隔離する

- ステータス: 置換 (ADR-0021 による)
- 記録日: 2026-08-29
- 関連: [ADR-0007](0007-viewport-crop-calibration.md), [ADR-0010](0010-client-side-display-policy.md), [ADR-0014](0014-box-theme-and-dom-reuse.md), [ADR-0015](0015-key-binding-policy.md), [ADR-0020](0020-arrow-target-navigation.md), [ADR-0021](0021-mode-wheel-with-calibration.md)

## 文脈

[ADR-0015](0015-key-binding-policy.md) の時点では、トップページのキーは
調整 (ズーム / 位置 / 保存 / リセット)・表示切替・鑑定法の切替・意匠の切替が
同居し、矢印キーは切り抜き位置の調整に割り当てられていた
([ADR-0007](0007-viewport-crop-calibration.md))。

今回「単体鑑定で矢印キーによって対象を選び替えたい」という要求が出た
([ADR-0020](0020-arrow-target-navigation.md))。矢印キーの取り合いになる。

調整 (ズーム・切り抜き位置) は**据え付け時に一度合わせれば済む**操作で、運用中は
ほとんど触らない。対象の選択は**運用中に常時使う**操作である。使用頻度が逆転している。

鑑定法の選択肢は鑑定盤 (画面左上) にテキストで開いていた。XR グラスでは視界の隅より
中央のほうが読み取りやすい。

## 決定

- 矢印キーは**鑑定の操作**に充てる。単体鑑定では対象の選び替え、広域鑑定では
  何もしない (案内メッセージだけ出す)。
- ズーム・切り抜き位置・保存・リセットは、`c` で出入りする**調整モードの中だけ**で
  効く。調整モード中は矢印/`+`/`-`/`0`/`s` が調整に効き、鑑定の操作
  (`m`/`Enter`/矢印での選択) は動かさない。`d` (映像ON/OFF) と意匠キーは調整と
  直交するので調整モード中も効かせる。
- 鑑定法の選択は画面中央の**円盤 (`#wheel`)** に出す。`m` で開き、
  **数字キーは即確定**、**矢印はカーソル移動で Enter が確定**。無操作 **3 秒**で
  自動キャンセルし、キー操作のたびに延長する。それ以外のキー (`Esc` や `m` を含む) は
  **取り消しにだけ**使い、本来の機能は動かさない。
- **Ctrl / Cmd / Alt 付きのキーには一切反応しない。Shift は除外しない**
  (`+` の入力に Shift が要るため)。

## 理由

- **頻度の高い操作を単独キーに置く**: 据え付け時にしか使わない調整が単独の矢印キーを
  占有し、常時使う対象選択が修飾キー付きになるのは逆である。前置きキーの手間は、
  使用頻度が低いほうに払わせる。
- **トグルであって 2 ストロークではない**: 調整は「少しずつ動かして確かめる」ため
  矢印を連打する。ADR-0015 の 2 ストローク方式 (`m` → 数字) をそのまま持ってくると、
  1 回動かすたびに前置きキーが要る。出入りのあるモードにした。
- **調整モード中に鑑定の操作を動かさない**: ADR-0015 の「待ち状態中は本来の機能を
  動かさない」と同じ理由。モードに入っていることを忘れて操作したときに、二重の効果が
  出るのを避ける。
- **修飾キー付きを無視する**: ADR-0015 から引き継ぐ。macOS の `Cmd+0` / `Cmd+=` /
  `Cmd+-` (ページの拡大縮小) を拾うと調整中の値が意図せずリセットされる。ただし
  **Shift だけは除外できない**。多くの配列で `+` は `Shift+=` として届くため、
  Shift 付きを弾くとズームの増加が効かなくなる。
- **円盤を画面中央に置く**: XR グラスでは視界の隅は読み取りにくく、頭の向きで狙う
  都合上、中央に注意が集まっている。選択肢を中央に出すほうが目線の移動が要らない。
  照準と重なるので、盤を開いている間は照準を消す。
- **数字は即確定、矢印は Enter 確定**: 数字は「どれを選ぶか」を一意に指せるので確認の
  一手を挟む意味がない。矢印は隣へ動かすだけなので、確定と分けないと通り過ぎた先で
  確定してしまう。
- **3 秒の自動キャンセルを維持し、操作で延長する**: ADR-0015 の値をそのまま引き継ぐ。
  ただし矢印で選んでいる最中に消えると使えないため、キー操作のたびに延長する。

## 結果

- 単独で使う数字キーは意匠の切替 (`1`〜`6`、暫定のデバッグ機能) だけになった。
  `0` は調整モードの中へ移ったので、意匠キーとは衝突しない。
- 鑑定法を増やすときは `frontend/index.html` の `MODES` に1行足すだけでよい。
  円盤の配置・数字キーの割り当て・案内文がそこから導かれる。円周上の角度は
  項目数から計算する。
- **引き受けた欠点**: 調整のたびに `c` で出入りする手間が増えた。据え付け時にしか
  使わない操作なので許容した。
- **引き受けた欠点**: `c` を押していることを忘れると、矢印が対象の選択ではなく
  位置の調整に効く。調整モード中は鑑定盤に専用のキー案内行を開き、状態表示を
  `調整中` にして見分けられるようにしている。
- ADR-0015 はこの ADR で置換する。

# ADR-0013: 枠は映像が実際に占める矩形を基準に配置する

- ステータス: 承認済み
- 記録日: 2026-08-18
- 関連: [ADR-0002](0002-detection-streaming-contract.md), [ADR-0011](0011-gaze-target-selection.md)

## 文脈

`#video` は `object-fit: contain` で表示されるため、ウィンドウが映像と同じ縦横比で
ないと、上下または左右に**レターボックスの帯**が付く。

枠を `#stage` 全体に対して配置すると、この帯のぶんだけ枠が映像からズレる。
実測で、1440x900 のウィンドウで最大 36px、正方形に近いウィンドウでは 175px ずれた。

## 決定

枠は `#stage` 全体ではなく、**映像が実際に占める矩形**を基準に配置する。
矩形は `/ws` の `source_size` とステージの実寸から求める。
**映像 OFF (AR 表示) でも同じ矩形を使う。**

## 理由

- **帯を除外する**: 上記の実測どおり、除外しないと枠が目に見えてズレる。
- **映像 OFF でも同じ矩形を使う**: `#stage` 全体へ引き伸ばすと、実世界に対する枠の
  縦横比が崩れる。AR 表示こそ現実との重なりが重要なので、映像の有無で基準を変えない。
- **`source_size` から求める**: このフィールドは既に毎フレーム届いているため、
  追加の通信が要らない ([ADR-0002](0002-detection-streaming-contract.md))。
  DOM から映像の実寸を測る方法もあるが、映像 OFF のときに測れなくなる。

## 結果

- ウィンドウの比率に関わらず枠と映像が一致する。
- `source_size` が未取得の間は `#stage` 全体にフォールバックする (接続直後の一瞬だけ)。
- 中心からの距離計算 ([ADR-0011](0011-gaze-target-selection.md)) もこの矩形を基準にする。

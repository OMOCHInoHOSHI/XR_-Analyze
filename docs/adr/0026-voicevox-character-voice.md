# ADR-0026: 読み上げの既定を VOICEVOX のキャラクター音声にする

- ステータス: 承認済み
- 記録日: 2026-08-30
- 関連: [ADR-0024](0024-llm-object-explanation.md), [ADR-0025](0025-inspector-voice-readout.md)

## 文脈

[ADR-0025](0025-inspector-voice-readout.md) で読み上げを macOS 同梱の `say` に決め、
`Grandpa` (日本語の老翁の声) を既定にした。しかし実機で鳴らしてみると、声が
「無口な職人鑑定士」([ADR-0024](0024-llm-object-explanation.md)) の人物像に合わなかった。

システムボイスは文章を読み上げるための声であって、人物を演じるための声ではない。
実機の `say -v '?'` に並ぶ日本語ボイスは 9 種しかなく、この中で選び直しても
幅が出ない。ADR-0025 は VOICEVOX を「常駐プロセスが増える」ことを理由に退けたが、
その判断は実際に声を聴く前のものだった。

## 決定

- `TTS_BACKEND` の既定を **`voicevox`** にする。VOICEVOX ENGINE (既定
  `http://localhost:50021`) に HTTP で繋ぎ、`/audio_query` → `/synthesis` の
  2 段階で WAV を得る。
- 既定の話者は **「青山龍星」のスタイル「不機嫌」(ID 82)** とする。
- `say` は残す。`TTS_BACKEND=say` でいつでも戻せる。
- 話者ID・話速・音高・抑揚を `VOICEVOX_SPEAKER` / `VOICEVOX_SPEED` /
  `VOICEVOX_PITCH` / `VOICEVOX_INTONATION` で調整できるようにする。

## 理由

- **声の選択肢が桁違いに広い**: macOS のシステムボイスが日本語 9 種なのに対し、
  実機の ENGINE 0.25.2 では **43 キャラクター・127 スタイル**が使える。同じ
  キャラクターでもスタイル (ノーマル / 不機嫌 / しっとり等) で調子が変わるため、
  「渋い年配の男性が淡々と告げる」ような具体的な人物像に対して選べる幅がある。
- **ADR-0025 の判断を改めた**: 常駐プロセスが 1 つ増えるコストは、声が人物像に
  合わないという体験上の欠陥より軽い。この作品の主題は異世界の鑑定であり、
  鑑定士の声はその中核にある。
- **差し替え可能にしておいた設計がそのまま効いた**:
  [ADR-0025](0025-inspector-voice-readout.md) で合成を `backend/tts.py` に閉じて
  あったため、移行は `synthesize()` に分岐を 1 つ足すだけで済んだ。フロントと
  `/speak` の契約は変わっていない。
- **個人の非商用利用にライセンス上の障害がない**: VOICEVOX は商用・非商用を問わず
  無料で使える。ENGINE を別プロセスとして起動し HTTP で叩くだけの構成なので、
  LGPLv3 のリンク条項には該当せず、本アプリのソース公開義務は生じない
  (ENGINE は LGPLv3 とソース公開不要な別ライセンスのデュアル、CORE は MIT)。
  ただしクレジット表記は義務であり、これは下記「結果」で引き受ける。
- **Gemma 4 に読み上げさせる案は成立しない**: `ollama show gemma4:e4b` の
  Capabilities には `audio` が並ぶが、これは音声の**入力** (最大 30 秒の音声を
  聞き取る・翻訳する) であって出力ではない。公式のモデルカードでも生成できるのは
  テキストだけである。ローカルで声を出すには、文を書くモデルとは別に音声合成が要る。
  Google のローカル実行可能な音声合成モデルも見つからなかった (Gemini の TTS は
  クラウド専用でオープンウェイトではない)。
- **「青山龍星・不機嫌」を既定にした**: 低くぶっきらぼうな声で、無口な職人鑑定士が
  淡々と告げる調子に最も近い。43 キャラクター・127 スタイルの中から低音・年配・
  落ち着いた声を 10 種に絞り、実際の鑑定文を鳴らして選んだ。スタイルまで含めて
  選べることが VOICEVOX の利点で、同じ青山龍星でも「ノーマル」では快活すぎる。
- **`say` を残した**: ENGINE を起動していない環境でも読み上げ経路の動作確認ができる。
  macOS 以外を含め、VOICEVOX を用意できない場合の退避先にもなる。
- **話者と発話パラメータを環境変数にした**: どの声が人物像に合うかは聴いてみないと
  決まらない。声の変更のたびにコードを触るのは無駄なので、`ollama pull` 済みの
  モデル名を環境変数で選ぶ [ADR-0024](0024-llm-object-explanation.md) と同じ形にした。

## 結果

- 鑑定士の声をキャラクター音声から選べるようになった。話速・音高・抑揚も
  環境変数で詰められる。
- **引き受けた制約**: VOICEVOX ENGINE (またはアプリ) の起動が必要になった。
  未起動のときは `/speak` が 503 を返し、鑑定文は表示されたまま無音になる。
  Ollama ([ADR-0024](0024-llm-object-explanation.md)) と同じ性質の依存が 1 つ増えた。
- **引き受けた制約**: **クレジット表記の義務**。既定の話者「青山龍星」の規約は、
  個人が生成した音声について「`VOICEVOX:青山龍星` とクレジットを記載すれば、
  商用・非商用で利用可能」と定める (企業が携わる形での利用は権利元への事前確認が
  要る)。現状は README に記載しているが、公開・配布する段階では画面にも出す必要が
  ある。
- **引き受けた制約**: 規約は話者ごとに異なる。`VOICEVOX_SPEAKER` を変えるときは、
  ENGINE の `GET /speaker_info?speaker_uuid=...` が返す `policy` (規約の全文が
  入っている) か公式サイトで、その話者の条件を確認しなければならない。
- **引き受けた制約**: macOS 版の ENGINE は GPU コアに対応せず CPU 合成のみとなる。
  実測で鑑定文 1 件あたり 1.3 秒 (23 文字) 〜 2.9 秒 (64 文字) かかり、`say` の
  0.5 秒より遅い。固定から声が出るまでは、鑑定文の生成 7.5 秒 + 合成 2 秒ほどになる。

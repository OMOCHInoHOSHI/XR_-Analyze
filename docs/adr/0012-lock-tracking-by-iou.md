# ADR-0012: 固定対象は IoU による簡易追従で引き継ぐ

- ステータス: 承認済み
- 記録日: 2026-08-18
- 関連: [ADR-0002](0002-detection-streaming-contract.md), [ADR-0010](0010-client-side-display-policy.md), [ADR-0011](0011-gaze-target-selection.md)

## 文脈

鑑定を固定 (`Enter`) しても、`/ws` の検出結果には**トラッキング ID が無い**ため、
次のフレームで同じ物体を指す手掛かりが無い。何もしないと、固定した直後のフレームで
選択が別の物体へ移ってしまい、固定という機能が成立しない。

オープン語彙モデルではフレーム間で**ラベル自体が揺れる**こともある。

## 決定

- 固定対象は「最後に確定した枠」として保持し、毎フレーム **IoU (重なり) が最大の検出**へ
  引き継ぐ。
- 閾値は**同じラベルなら 0.1、ラベルが揺れた場合は 0.4**。
- 見失ったら破線 + 半透明 (`[見失い]`) で表示し、**2 秒 (`LOCK_GRACE_MS`)** 戻らなければ
  自動解除する。
- 鑑定法を切り替えたときは固定を解除する。

## 理由

- **本格的なトラッカーを入れない**: ByteTrack などを導入する前に、「固定」という機能が
  実用になるかを確かめたい段階である。IoU の引き継ぎだけで足りるなら、追加の依存も
  推論コストも要らない。
- **同ラベルは緩く、ラベル違いは厳しく**: オープン語彙モデルではラベルが揺れるため、
  ラベル一致だけを条件にすると簡単に見失う。かといって揺れた検出まで緩く拾うと、
  隣の物体へ乗り移る。ラベルが一致しているという追加の証拠がある場合だけ重なりの
  条件を緩める。
- **猶予を設ける**: 一瞬の未検出で固定が外れると使い物にならない。逆に無期限に残すと、
  対象が視界から消えても枠が残り続ける。2 秒はその折衷。
- **鑑定法の切替で解除する**: 広域鑑定中は固定の表示が無いため、そのまま残すと
  「見えない固定状態」が生き続け、単体鑑定へ戻ったときに意図しない対象が固定されている。

## 結果

- 追従はあくまで簡易的なもので、同種の物体が重なる場面では乗り移りうる。
- 将来トラッキング ID を `/ws` に載せるなら ([ADR-0002](0002-detection-streaming-contract.md))、
  この節はまるごと置き換えになる。その時点でこの ADR を置換する。
- 猶予切れは新フレームが来なくても効くよう、期限後の描き直しをタイマーで予約している
  ([ADR-0010](0010-client-side-display-policy.md))。再追従できたら予約は取り消す。

# ADR-0028: 読み上げている間は見失っても対象を解除しない

- ステータス: 承認済み
- 記録日: 2026-08-30
- 関連: [ADR-0012](0012-lock-tracking-by-iou.md), [ADR-0020](0020-arrow-target-navigation.md), [ADR-0025](0025-inspector-voice-readout.md)

## 文脈

[ADR-0012](0012-lock-tracking-by-iou.md) と [ADR-0020](0020-arrow-target-navigation.md)
で、固定した対象は IoU で追従し、見失ってから `SEL_GRACE_MS` (2秒) 経つと自動で
解除すると決めた。枠だけが取り残されるのを避けるための規則である。

[ADR-0025](0025-inspector-voice-readout.md) で読み上げを入れたことで、この規則が
体験を壊すようになった。自動解除は `clearSel()` → `closeExplain()` → `stopSpeak()`
と連鎖するため、**鑑定文を読み上げている最中に対象がカメラの画角から外れると、
窓が閉じて声が途中で切れる**。手元の物を鑑定して顔を上げる、対象を持ち替える、
といった自然な動作で起きてしまう。

## 決定

- **説明ウィンドウが開いている間は、見失いによる自動解除を行わない。**
- 枠の「見失い」表示 (`selLostAt` による状態表示) はそのまま残す。解除しないことと、
  追えていることは別である。
- 窓を閉じた時点で猶予を過ぎていれば、そこで通常どおり解除する。窓を閉じたのに
  固定だけが残る状態は作らない。

## 理由

- **読んでいる最中の関心は画面の中にある**: 鑑定文が出ている間、利用者が見ている
  のは窓であって画角ではない。その時点で「対象がカメラに映っているか」は問題に
  ならない。映っていないから鑑定を取り消す、というのは道具の都合である。
- **声が途中で切れるのは、文字が消えるより強く感じる**: 表示だけなら消えたことに
  後から気づくが、読み上げは切れた瞬間に分かる。鑑定士が言い終わる前に黙る形になり、
  [ADR-0024](0024-llm-object-explanation.md) で作った人物像も損なう。
- **自動解除そのものは残す**: 窓を閉じれば元の規則に戻る。枠だけが取り残される問題
  ([ADR-0012](0012-lock-tracking-by-iou.md)) は、窓を開いていない通常の状態では
  従来どおり防がれる。
- **窓を閉じる操作を解除の起点にした**: 窓は `Enter` / `Esc` で明示的に閉じる
  ([ADR-0019](0019-key-binding-policy-v2.md))。利用者が読み終わったと判断した
  時点で規則を戻すのが自然で、時間切れという見えない基準で決めるより分かりやすい。

## 結果

- 手元の物を鑑定しながら顔を上げても、鑑定文の表示と読み上げが最後まで続く。
- **引き受けた制約**: 窓を開いたまま放置すると、対象を見失っても固定が残り続ける。
  解除は窓を閉じるまで起きない。窓は `Enter` / `Esc` で閉じられるので、抜け道の
  ない状態にはならない。
- **引き受けた制約**: 窓が開いている間、枠は「見失い」の表示のまま画面に残る。
  追えていないことは見て分かるが、消えはしない。

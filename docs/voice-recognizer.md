# 音声コマンド (音声認識)

マイクで決まった言葉を聞き取り、キーと同じ操作をする機能の仕様。
設計判断と、ほかの方式を採らなかった理由は
[ADR-0045](adr/0045-voice-commands.md) を参照してください。

## 使い方

本画面 (検出が始まった後の画面) で、マイクに向かって次の言葉を言います。起動画面
(カメラとモデルを選ぶ画面) では効きません。キー操作もこれまでどおり全部使えます。

| 言葉 | 効く場面 | 動作 | 同じ操作のキー |
|---|---|---|---|
| 「モード変更」 | 円盤が閉じているとき (調整モード中も効く) | モードの円盤を開く | `m` |
| 「たんたいかんてい」「いち」 | 円盤が開いているときだけ | 単体鑑定に決めて円盤を閉じる | `1` |
| 「こういきかんてい」「に」 | 円盤が開いているときだけ | 広域鑑定に決めて円盤を閉じる | `2` |
| 「とじる」 | 円盤が開いているとき | 円盤を閉じる (モードは変えない) | `Esc` |
| 「とじる」 | 鑑定ウィンドウが開いているとき | ウィンドウを閉じ、読み上げも止める (固定は残る) | `Enter` / `Esc` |
| 「鑑定」 | 単体鑑定中 (下の表) | 対象を固定して鑑定文を表示・読み上げ | `Enter` |
| 「終了」 | いつでも | アプリを終了する | (コンソールで `Ctrl+C`) |

- 「いち」「に」は円盤が開いているときしか受け付けません。普段の会話で勝手にモードが
  変わることはありません。
- 今と同じ鑑定法を選んだときは、キーと同じく「変更なし」と出て、固定も解除されません。
- 声で開いた円盤は **6 秒**、`m` キーで開いた円盤は今までどおり **3 秒**で、何も
  選ばなければ閉じます。開いたあとに矢印キーを押すと延びます。声で開いてから矢印キーと
  `Enter` で選ぶ、のように混ぜても構いません。

### 「鑑定」の動き

| 状態 | 動作 |
|---|---|
| 単体鑑定で、固定していない | 選択中の対象 (無ければ照準の対象) を固定して鑑定する |
| 単体鑑定で、固定中 (鑑定ウィンドウは閉じている) | **照準が今狙っている対象へ固定を移して**鑑定し直す |
| 照準の先に何も無い | 「固定する対象がありません」/「照準の先に対象がありません」と出す |
| 広域鑑定中 | 「鑑定は単体鑑定のみ」と出す |
| 調整モード中 | 何もしない |

Enter は固定中に押すと解除になりますが、声の「鑑定」は解除しません。
「鑑定 → とじる → 次の物を見る → 鑑定」と、声だけで続けて鑑定できるようにするためです。
固定を解除したいときは、今までどおり `Esc` か `Enter` を使います。

### 受け付けない場面

| 場面 | 受け付ける言葉 | それ以外の言葉 |
|---|---|---|
| 鑑定ウィンドウが開いている | 「とじる」「終了」 | 何もしない・何も出さない |
| 円盤が開いている | 「たんたいかんてい」「いち」「こういきかんてい」「に」「とじる」「終了」 | 何もしない (円盤はそのまま) |
| 円盤が閉じている | 「モード変更」「鑑定」「終了」 | 何もしない |

鑑定ウィンドウが開いている間に絞っているのは、鑑定士の読み上げをマイクが拾っても
誤動作しないようにするためです (鑑定文には「鑑定」がよく出てきます)。

### 終了

「終了」と言うと、確認なしで次のようになります。

1. 読み上げを止め、画面全体に「終了しました / このタブは閉じて構いません」と出す。
2. サーバが約 1 秒で止まり、カメラとマイクを解放する。
3. exe で動かしている場合は、黒いコンソール窓も閉じる。

- ブラウザのタブは、ページの側から閉じられません。終了の表示を出して終わりにします。
- 調整モードで変えた値を保存 (`s`) していなければ、その値は失われます
  (Ctrl+C で止めたときと同じ)。
- 終了の後は「再接続中」の表示は出ず、キーも効きません。

## 画面の表示

鑑定盤 (画面左上) に「音声」の行があり、マイクの音量を波形で出します。色は枠と同じ
意匠の色 (`--c`) です。

| 状態 | 波形 | 右の短い文字 |
|---|---|---|
| 聞いていて、静か | 平らな線 (ごくわずかに揺れる) | なし |
| 話している | 声の大きさに合わせて中央がギザギザに振れる | なし |
| 聞き取って受け付けた瞬間 | 線が一瞬光る。報せ欄に「≫ 言葉 ── 結果」 | なし |
| 鑑定ウィンドウが開いている | 半透明 (振れはする) | とじる / 終了 |
| モデルの読み込み中 | 平らな破線 | 準備中 |
| 無効 (`VOICE=0`) | 平らな破線 | 無効 |
| マイクが無い・開けない | 平らな破線 | マイク無し |
| モデルが無く取得もできない | 平らな破線 | モデル未取得 |
| 別のタブが音声を使っている | 平らな破線 | 別のタブで使用中 |
| サーバにつながっていない | 平らな破線 | 未接続 |

- 波形の形: 両端は平らなまま、中央の 9 つの頂点だけが上下に交互に振れます。角は
  丸めません。音量は 1 秒に約 30 回届き、立ち上がりは速く、減衰はゆっくりにならします。
- 音量は -60 dBFS 以下を 0、-10 dBFS 以上を 1 として、その間を dB で直線に並べています。
  話しても振れないときは、マイクの入力レベル (OS のサウンド設定) を確かめてください。
- 鑑定ウィンドウの見出しは「Enter/Esc・「とじる」で閉じる」、円盤の中央には
  「声:「いち」「に」「とじる」」と出ます。

## 準備

- `pip install -r backend/requirements.txt` で `vosk` と `sounddevice` が入ります。
  Windows で `XRAnalyze.bat` から起動している場合は、requirements.txt の変更を見て
  自動で入れ直します。
- **初回の起動**で、日本語の音声モデル `vosk-model-small-ja-0.22` (約 50MB、展開後
  95MB) を取得して、プロジェクトのルート (exe では exe の隣) に置きます。2 回目以降は
  ネットなしで動きます。モデルの取得はサーバの起動を待たせません (取得中は「準備中」)。
- マイクは OS の既定のマイクを使います。マイクを後から挿した場合も、3 秒ごとに開き直す
  ので、そのまま使えるようになります。

### 設定 (環境変数)

| 変数 | 既定 | 説明 |
|---|---|---|
| `VOICE` | 1 | `0` で音声コマンドを使わない (マイクに一切触れない) |
| `MIC_NAME` | (空) | 使うマイクの名前の一部 (大文字小文字は無視)。空なら OS の既定のマイク |
| `VOSK_MODEL` | ./vosk-model-small-ja-0.22 (exe では exe の隣) | Vosk のモデルフォルダ |
| `VOSK_MODEL_URL` | alphacephei.com の vosk-model-small-ja-0.22.zip | モデルの取得元。空にすると取りに行かない (手で `VOSK_MODEL` に置く) |

ネットにつながらない PC では、別の PC で
<https://alphacephei.com/vosk/models/vosk-model-small-ja-0.22.zip> を取得・展開し、
`vosk-model-small-ja-0.22` フォルダごとプロジェクトのルート (exe では exe の隣) に
置いてください。

## 仕組み

```
マイク ──> [backend/voice.py] sounddevice で 16bit モノラル、1/30 秒ずつ
            ├─ 音量 (0〜1) を計算
            └─ Vosk (言葉を 8 つ + [unk] に限定) で認識
                 └─ 結果が「ちょうど 1 つのコマンド」のときだけ採る
        ──> WebSocket /voice で {"state", "level", "cmd", "word"} を送る
        ──> [frontend/app.js] 今の状態 (円盤・鑑定ウィンドウ・鑑定法) を見て、
            キーと同じ関数を呼ぶ。波形を描く
```

- **認識する言葉の限定**: `backend/voice.py` の `PHRASES` が唯一の出所です。Vosk には
  これと `[unk]` だけを grammar として渡します。関係ない会話は `[unk]` になります。
- **ちょうど 1 つだけ受け付ける**: 認識結果が `[unk] 鑑定 [unk]` のように前後に何か
  付いていたら捨てます。読み上げの文の途中に出るコマンド語で動かないようにするためです。
- **区切りの補い**: Vosk が発話の区切りを付けない場合でも、途中の認識結果が
  `SETTLE_SEC` (0.6 秒) 変わらなければ確定させます。
- **タブが複数あるとき**: 聞き取った言葉は、最後に開いたタブにだけ送ります。
- **終了**: ブラウザが `POST /shutdown` を呼び、サーバは Ctrl+C と同じ手順で止まります
  ([ADR-0032](adr/0032-prompt-shutdown.md))。この PC からの要求だけを受け付けます。

`/voice` と `/shutdown` の形式は [api.md](api.md) を参照してください。

### 言葉を増やすとき

1. 言葉がモデルの語彙 (`vosk-model-small-ja-0.22/graph/words.txt`) にあるか確かめる。
   語彙に無い語は、grammar に入れても Vosk が黙って無視します。語彙の区切り
   (例: 「単体 鑑定」) どおりにスペースで区切って書きます。
2. `backend/voice.py` の `PHRASES` に「言葉 → コマンド名」を足す。
3. `frontend/app.js` の `runVoiceCommand` に、どの場面で何をするかを書く。
4. `backend/tests/test_voice.py` の `test_parse_accepts_exact_commands` に足す。
5. この文書の表と、README の表を直す。

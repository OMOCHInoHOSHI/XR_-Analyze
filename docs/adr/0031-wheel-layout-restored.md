# ADR-0031: 円盤の配置と回転の向きを ADR-0023 の形に戻す

- ステータス: 承認済み
- 記録日: 2026-08-30
- 関連: [ADR-0021](0021-mode-wheel-with-calibration.md), [ADR-0023](0023-rotating-mode-wheel.md), [ADR-0030](0030-wheel-turns-with-the-key.md)

## 文脈

[ADR-0030](0030-wheel-turns-with-the-key.md) で「`→` を押したら盤が右回りに回る」
ようにし、そのために項目の配置を反時計回り (12時=壱 / 8時=弐 / 4時=参) へ変えた。

実機で表示を見た利用者から、配置を元に戻してほしいという要求が出た
(「右下に弐、左下に参が来るように」)。回転の向きより、**盤の上で 壱・弐・参 が
時計回りに並んで見えること**のほうが読みやすい、という判断である。

## 決定

- 項目の配置を [ADR-0023](0023-rotating-mode-wheel.md) の形に戻す
  (12時=壱 / 4時=弐 / 8時=参、12時から時計回りに等間隔)。
- 盤の回転の向きも合わせて戻す。`→` / `↓` で盤は**左回り**に回り、次の項目が
  12時の指標へ来る。
- [ADR-0030](0030-wheel-turns-with-the-key.md) は破棄する。

## 理由

- **配置を優先した**: 円盤に並ぶ項目は、選ぶ前に一覧として目に入る。並びが
  読み順 (壱→弐→参) と揃っているほうが、どこに何があるかを覚えやすい。
  一方、回転の向きは操作している最中の一瞬しか見えない。実機で見比べた結果、
  読みやすさのほうが上回った。
- **配置と回転を切り離せない**: 配置を時計回りに戻したまま盤を右回りに回すと、
  12時へ来るのは「次」ではなく「前」の項目になる。矢印の進む向きと数字キーの
  並び (壱=1 / 弐=2 / 参=3) が食い違うため、
  [ADR-0030](0030-wheel-turns-with-the-key.md) の狙いだけを残すことはできない。
  どちらか一方しか選べず、配置を採った。
- **ADR-0030 の指摘自体は誤りではない**: 「押した向きと盤の動く向きが逆」という
  引っかかりは実在する。それを承知のうえで、並びの読みやすさと引き換えにした。

## 結果

- 盤の並びは 12時=壱 / 右下=弐 / 左下=参 に戻った。`→` を押すと盤は左回りに
  回り、次の項目が 12時へ来る。
- [ADR-0023](0023-rotating-mode-wheel.md) の「12時から時計回りに等間隔」という
  記述が、そのまま実装と一致する状態に戻った。
- **引き受けた欠点**: `→` を押したときに盤が左へ回る。
  [ADR-0030](0030-wheel-turns-with-the-key.md) で挙げた食い違いはそのまま残る。

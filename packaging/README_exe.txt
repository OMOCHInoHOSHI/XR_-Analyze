XR Analyze (Windows 版)
=======================

■ 起動
  XRAnalyze.exe をダブルクリックします。黒いコンソール窓が開き、少しすると
  ブラウザで起動画面が開きます。

  1. 使うカメラをドロップダウンから選ぶ (下の縮小画像で、どのカメラかを見分けられます)
  2. 検出モデルを選ぶ (「初回にダウンロード」のものは開始時に自動で取得します)
  3. 「この設定で開始」(Enter) を押す

  ブラウザが開かないときは http://127.0.0.1:8100/ を開いてください。

■ 終了
  コンソール窓を閉じるか、窓の中で Ctrl+C を押します。

■ GPU
  NVIDIA の GPU (RTX 20 系以降) があれば自動で使います。GPU が使われないときは
  NVIDIA のドライバを最新 (バージョン 580 以降) に更新してください。GPU が無い PC
  では CPU で動きます (遅くなります)。起動画面の上に「推論デバイス」が出ます。

■ 鑑定文の生成と読み上げ
  別途 Ollama と VOICEVOX をインストールして起動しておく必要があります。
  無くても検出は動きます (鑑定文・読み上げが出ないだけ)。

■ ファイル
  このフォルダに次のものが作られます。フォルダごと移動・コピーしてかまいません。
    calib.json         画面の調整値 (調整モードの s で保存)
    explain_cache.json 鑑定文のキャッシュ
    speak_cache\       読み上げ音声のキャッシュ
    *.pt               ダウンロードした検出モデル
    XRAnalyze.log      最後に起動したときのログ (その前の回は XRAnalyze.prev.log)
                       落ちたときは、このファイルを見ると原因が分かります

■ 起動画面を出さずに始める
  コマンドプロンプトで  XRAnalyze.exe --no-select
  (環境変数 CAM_INDEX / MODEL などの設定で、すぐに検出を始めます)
